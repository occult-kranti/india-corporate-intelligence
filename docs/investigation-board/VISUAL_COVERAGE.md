# Desktop presentation and tutorial coverage

This release treats the retained application as one research archive. The new board is an additional working surface, not a replacement for the existing analytical routes. The treatment is systematic rather than a claim of 61 individually rebuilt page layouts.

## Coverage by surface

| Shared Workspace and sector dossiers | Unified evidence docks, ledger rows, tables, dossier cards and Casebook surface | Map, Connections, Evidence, Casebook and Dossier; all original filters, sources, CSV, comparisons and path analysis | Shared controls plus page-specific controls and source limitations |

## What has intentionally not changed

The source data and claim status are unchanged. Tier glyphs, relationship direction, financial-stage semantics, map placement precision and chart-series encodings retain their meaning. All original route/page modules remain present. The separately hosted ProtestAtlas is linked, but its external pages are outside this repository and are not claimed as redesigned.

## Visual acceptance

Desktop interaction tests generate screenshots for the board at 1280px and 1600px, native inspector/tutorial dialogs and representative retained React/static surface families. Route rendering covers every retained route in addition to the screenshot sample. Image existence is a CI artifact gate, not a substitute for viewing the images. Release acceptance requires actual screenshot review; until that review is recorded, visual acceptance remains pending.
