# Product and engineering panel

These are delegated AI design, spatial, data, research and adversarial-review perspectives. No human expert panel or user study is claimed. Root coordinates the implementation and release; evidence, not model agreement, decides a claim.

## Round one — decisions before the build

| Perspective | Observed problem or question | Adopted decision |
| --- | --- | --- |
| Product/design | The previous three-column workspace gave roughly 420px to the geographic map and made all surfaces look alike. | Make a larger geographic stage, a warm paper case dock, petrol cartography, jade controls and a wider labelled sector rail. Preserve all original dossiers. |
| Reader acquisition and orientation | Many destinations and graph vocabularies obscure the first useful task. | Put the unified atlas at the homepage, expose sector destinations directly, and make place → case → source → next connection the visible journey. This is a design hypothesis, not a measured conversion claim. |
| Spatial engineering | Decorative buildings or state-centre pins would imply unsupported location precision. | Extrude the exact retained geometry; show source-backed public facilities only. Label schematic symbols, count-based height and fixed modern boundaries. Include a full 2D and keyboard fallback. |
| Graph/data | A larger node cloud does not establish additional money flows. | Add direction-aware exploration and exact trails to five hops, an uncapped matching ledger and source/response-closed exports. Similar names, co-occurrence and text similarity never become edges. |
| Research | Current legal status and financial-stage distinctions can defeat an attractive narrative. | Add 2011–2026 laws and new transaction/audit chains with current responses. Explicitly separate proposed, awarded, borrowed, advanced, paid, recovered and estimated amounts. |
| Team lead | Replacing the stack would discard mature local casebooks, route history and regression tests. | Retain React/TypeScript and add lazily loaded Three.js for the new spatial capability. Keep reproducible local scripts and primary-source data; no account or paid API is required for the atlas. |
| Latest geographic and international brief | State geometry alone cannot orient a reader within cities and villages or represent foreign counterparties honestly. | Add a lazy MapLibre/OpenFreeMap street underlay, explicit place search, attributed building context and an offline fallback. Add typed international-finance and defence-trade routes with country identities in the graph, without fabricated geographic payment pins. |

## Round two — findings on actual code, records and screens

| Reviewer | Concrete finding | Correction |
| --- | --- | --- |
| Independent design owner → root composition | Desktop home canvas began at y814; mobile first screen contained no map. | Shorten the headline, compact desktop sector/time controls, collapse mobile time controls, rely on the mobile shell sector navigation, and remove the duplicate map state selector where Place already exists. |
| Independent design owner → case presentation | Paper dock text touched its edges and dates had low contrast. | Add explicit inset spacing and dark paper-date/arrow colours. |
| Independent design owner → dedicated money trail | At 1440px the case brief fell below the map. | Recompose the case index as a horizontal strip, with map and source-backed case brief beside one another. |
| Independent design owner → mobile dossier | Context framing pushed the requested reading title to y820. | Compact the contextual map into a return-to-map control on an explicit mobile dossier entry. |
| Root → network controls | An externally supplied entity could override later local clicks; source opening could leave two evidence readers stacked. | Synchronize external selection into local focus and close the network reader before delegating source inspection. |
| Root → temporal consistency | A separate implicit graph date range narrowed results despite All history in the parent. | Start the graph with the parent scope; expose independent dates without an invisible default restriction. |
| Root → allegation discoverability | The case feed exposed explicit case records but hid sourced alleged relationships retained in the graph. | Add a separately counted alleged-link view, with source, status and responses; do not relabel ordinary relationships as cases or corruption. |
| Adversarial research | An NDTV price comparison omitted the subsequent SAST price-difference notice. | Retrieve and include the notice, distinguishing a stated additional payment from proof of settlement. Other research corrections are recorded in PANEL_RESEARCH.md. |
| Independent technical audit | Shared search included endpoint/source context while the atlas case feed searched a narrower text surface. | Use one registry-aware matcher for the evidence view, case feed, network and source-site eligibility; retain explicit empty-layer semantics. |
| Geographic engineering | The development dependency scanner treated archived third-party HTML receipts as possible application entries. | Restrict Vite dependency discovery to the real application index; retained source archives remain research artifacts. |

Final visual confirmation, browser results and source corrections are recorded with the release evidence. Any remaining precision or coverage limit must stay visible; a better design does not upgrade a claim's evidence tier.
