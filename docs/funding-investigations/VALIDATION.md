## Technical acceptance

The offline gates check invalid financial stages and amounts, missing/tampered citations, inherited graph references, path direction and traversal bounds, hidden aggregation or probability fields, fixed-query receipts and dependency fingerprints. The adapter checks every case's entity/edge/record/source closure and every exported original object, including the track-wide rejected-join sources. Explicit identity flags prevent the graph from silently guessing unresolved counterparties.

The browser gate exercises all 28 files and downloaded research packets, every track and evidence-status filter, URL/history, source popups and original URLs, keyboard dismissal/focus, map/network readers, missing selections, the existing-sector explorer, all 13 search questions, coverage/roadmaps, and 320/390px mobile controls. Screenshots and machine-readable receipts are written outside the repository. The shared route/map tests remain in place.

Desktop/mobile visual review produced one bounded correction group: replace the tall mobile register with a native file selector and explicitly center the source dialog after the global CSS reset. No user-participant testing or live third-party tile availability is claimed.

Its failures concerned an energy checkbox timing assertion, a finance tab timeout, finance reset rendering time, a tender whole-body percentage assertion and a tender keyboard-link budget. Three were reproduced on an older build; the two isolated interaction failures had unresolved causes. The extra navigation entry adds another focus stop. The long legacy suite is distinct from the deployment workflow's required gates.

The first mistaken AESL page extract was overwritten before its exact bytes were archived. The initial ranking output, its old metadata/hash and the reason for correction remain, and the final correctly located extract is verified; the superseded extract cannot be reproduced byte-for-byte from this release.

The main inherited application bundle remains large. This release defers the new cross-sector search chunk until its tab is opened; it does not claim to have solved the wider bundle-size issue. Map coordinates are case associations on current state boundaries, not historical borders or payment locations.

Publication is accepted only after the final build and applicable browser/data checks pass, then the branch commit, deployed Git tree and unauthenticated public asset bytes are compared. The public release receipt is an external artifact; any final outcome is appended below.
