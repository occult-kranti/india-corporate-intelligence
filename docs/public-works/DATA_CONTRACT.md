# Public works evidence contract

Snapshot 2026-10-06. Input files: `research/raw/public-works/roads-research.json`, `services-research.json`, `state-research.json`. Assembly is deterministic and hashes its inputs. No tender-stage row becomes a payment, completed asset or verified repeated work.

Every file may contain `sources`, `entities`, `relationships`, `cases`, `rules`, `localities`, `discovery`. Each array defaults empty. IDs must be globally unique. Sectors are `roads`, `electricity`, `water`, `hospitals`, `schools`, `police`, `military`, `recruitment`, `administration`. State codes are uppercase postal-style codes from the existing water state roster. Scope is `national`, `multi-state`, `state`, `district`, `city`, `village`, `project` or `unknown`. National context is retained when selecting a state; an unknown locality does not inherit national records as local evidence.

Common geographic dimensions: `sectors: string[]`, `stateCodes: string[]`, `localityIds: string[]`, `scope`. All three arrays and scope must be explicitly reviewed in every research record. Missing geography fails the raw input gate; genuinely unknown geography uses scope `unknown`. Never infer work location from a buyer's or publisher's address.

- Source: `id,title,url,publisher,publishedAt` (ISO date, ISO month or null), `period,retrievedAt,retrievalStatus,locator,summary,limitations[]`, common dimensions, `type` (`document`,`dataset`,`portal`,`news`,`discussion`), `tier` (`documented`,`reported`,`self-reported`). `retrievalStatus` describes the actually read artifact; a search-result snippet is not read evidence. Publication time, audit period and contract date are distinct.
- Entity: `id,label,type,identityBasis,sourceIds[],sectors[]`, optional common geography, `resolved` boolean. Types: authority, company, person, party, project, institution, law, group. A group is an explicitly bounded consolidated reporting perimeter, not a legal payer. The resolved boolean must be explicit after identity review. An unresolved identity gets no relationship edges. Source IDs and a substantive identity basis are required.
- Relationship: `id,from,to,kind,label,tier,sourceIds[],fromDate,toDate,summary,limitations[]`, common dimensions. Dates are nullable. `from`/`to` resolve to entity IDs. Kinds describe records such as award, funds, owns, role, contribution, regulates, audits, response; proximity is not influence. Analytic links require `alternativeExplanations[]` and `falsifier`; allegations require a linked response.
- Case: `id,title,summary,sectors[],stateCodes[],localityIds[],sourceIds[],attribution,response,alternativeExplanations[],falsifier`, optional `kind` (`audit-finding`,`judicial-finding`,`reported-event`,`analytic-question`,`methodology`), `status`, `locator`, `period`. An optional amount carries `amount,valueUnit,amountStage` (`estimate`,`allocation`,`release`,`award`,`payment`,`expenditure`,`audit-estimate`). Preserve the auditee's response as prominently as the audit finding. No unsupported misconduct scores.
- Rule: `id,title,summary,sourceIds[],sectors[],effectiveFrom,effectiveTo,jurisdiction,applicability,change,limitations[]`, optional `publishedAt,locator`. Effective dates are nullable. An unknown date cannot support a retrospective breach test. Goods, works, services, central government, states and defence acquisition have distinct applicability.
- Locality: `id,name,stateCode,kind` (district/city/village/block/project), optional `aliases[]`, `districtName`.
- Discovery: `id,title,url,summary,sourceIds[],sectors[],stateCodes[],localityIds[],scope,steps[],limitations[]`. Discovery is a retrieval route, never matching local evidence.

Amounts must keep currency and accounting stage; do not add tender estimates, awards, public grants and spending. An issue indicator is a review question. A political contribution, official role, corporate ownership or short graph path alone establishes no award influence.

Existing CPPP reuse: 4,921,960 raw scraped rows; 3,385,233 after the committed dedup rule. Current workspace holds committed aggregate outputs, not the 3.45 GB original Arrow data. This extension derives reproducible buyer-label sector views from those outputs, preserving hashes and their reported tier. No row-level repeated-work scan is represented as performed.
