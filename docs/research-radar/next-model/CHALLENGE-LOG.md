8 October 2026, America/New_York. This is a review by AI agents, not a human journalistic or academic review board. Entries below preceded inspection of new final-test candidate outputs.

| Challenge | Evidence and decision | Consequence |
|---|---|---|
| The previous test is no longer independent | The prior 20 questions, labels and complete results are public. | Preserve it as an exhausted regression set. Author 24 new questions in six case families, freeze their bytes, and allow one development-selected final candidate. |
| A source family is not the same thing as a split group | The draft graph dataset grouped the original Tamil Nadu loan, amendment, contract award and completion report into one case component. | Keep that component intact for train/test separation, but use a separate exact-URL source lineage for duplicate-collapsed metrics. Otherwise retrieving an old loan could receive false credit for a later completion report. |
| Expanded graphs contain duplicate evidence | Three Telangana audit summaries cite one original PDF; Akshaya Patra and NSAP sources recur across modules. | Quarantine duplicate URLs from training; assess actual summarized passage relevance separately and collapse original-source lineage when measuring coverage. Repeated reports are not independent confirmation. |
| Unknown graph edges are not negative facts | The repository cannot observe every invoice, beneficial owner, private transfer or corrected eligibility decision. | Only explicitly judged wrong-query documents enter retrieval negative sampling. Missing award/payment/ownership links remain unknown; no synthetic corruption labels. |
| A late archive cannot establish an earlier information set | The tender audit found 17,704 uniquely linked notice/award pairs, but only one had both retained notice scrapes before closing and its award after closing. Most award closing-date fields disagreed with the matched notice closing date. | Do not train and advertise historical forecasting from these post-event fields. Archive-conditional reconstruction must be labelled separately. |
| A public API snapshot can start a future cohort | A fresh official World Bank API capture supplies an observable denominator of currently active India projects. | Preregister future metadata targets with hashes, an observation window and unknown/censoring rules. No outcome or probability is estimated at registration. |
| Counterevidence must be measurable in selection | The first label draft had no explicit counterevidence metadata, making the promised development tie-break undefined. | The data owner reviewed and marked 17 existing training and five development questions that actually request a denial, corrective response, alternate explanation or legal limit; source/query content and the independent holdout were unchanged. |
| Better fusion is not proof of better fine-tuning | Dense-plus-BM25 reciprocal-rank fusion can change ranking even without a weight update. | If development selects fusion, compare it to the same fusion of BM25 and its untuned encoder, separately retaining BM25 and old MiniLM controls. |
| Large or multilingual pretrained models need local validation | The independent test contains English questions over retained public-source summaries. | Do not infer Hindi/Indic-language, OCR, full-document, factual-truth or future-event accuracy from this benchmark. |
| Path traversal can preserve an unsupported cash inference | A guarantee, equity relationship, award notice or programme-wide disbursement does not identify a payment to a particular contractor. | Preserve edge types, directions, source IDs, money stages and limitations. Expected stop conditions accompany all six held-out case families. Structural preservation is tested separately from learned retrieval. |
| Derived money rows need their own integrity check | Initial trace validation protected canonical edge amounts but did not separately compare displayed money cells or every path’s cash-flow flag. | The trace owner added exact derived-money projection checks and per-path non-inference checks, with mutation tests, before the final test invocation. |
| Receipt hashes alone are incomplete provenance checks | A matching checksum only says that stored bytes have not changed. | The World Bank resolver also checks the India filter, official endpoint URLs, pagination, record IDs, counts and ordered capture timestamps. Selection of the first eligible future capture still requires an independently reviewed collection history. |

Final scores, promotion decisions and actual execution receipts must be reported separately after the selected checkpoint is frozen. No threshold in the prospective evaluation protocol is changed by these notes.
