# Dependency map and release gates

A. Frozen adapters [implemented] → B. UI source drilldown [parallel] → C. Fresh original verification [open] → D. Event/entity resolution [open] → E. Time-valid typed paths [blocked on C,D] → F. Public publication [explicit approval required].

A preserves separate upstream schemas and current unknowns. B must expose source access depth, inherited assertions, dates and map precision. C needs original citations per material claim, publisher-family deduplication, current status follow-ups and outcome updates. D requires identifiers, dates and explicit participation/funding/support/opposition statements, never common geography. E requires valid intervals, evidence grade, supersession and denial treatment; it cannot operate on date-unknown imported edges. F requires license/attribution review, human editorial review of consequential inherited claims and authorization.

Parallel expansion: India core adapter → sector fleet adapters (energy, capital, finance, force, NGO; each can be MB-scale) → duplicate/canonical ID audit → original verification. Do not claim core Atlas import is the complete corporate database. deep-universe.json is cached as inspected schema evidence only; its 2,599 securities are not silently added as investigated entities.

Protest expansion: pinned 84-episode baseline → candidate research overlays → duplicate/episode-scope review → source verification → status/outcome refresh. Updates must attach to an existing episode rather than inflate counts. Unknown country coverage is not absence of protests.

Needed evaluation sets: rejected same-name joins; shared-country nonlinks; different episodes in one city; AP/Reuters syndications; source contradiction; court procedural vs merits outcomes; amount range/stage conflicts; parent/subsidiary identity; expired roles; UNKNOWN validity paths; source-rights restrictions. Require a false-positive-focused held-out test before any model-suggested link can become a published edge.
