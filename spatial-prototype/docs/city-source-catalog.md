# Open building sources for a felt-world overlay

Verified 15 October 2026. No dataset here proves that a person is at a building. Global coverage does not mean complete or current geometry for every city.

## Operational choice

Use the three checked OSM samples now. Add Overture extracts for more city coverage after validating footprint quality, public-building selection, heights and source attribution. Upgrade selected cities with official roof-aware municipal models when their license and format are confirmed. Keep the source dataset, investigative records, and application code separate.

Microsoft’s current direct repository uses CDLA Permissive 2.0; Overture’s buildings theme remains ODbL. These are different distributed artifacts. The current Overture attribution page still identifies its Microsoft input under ODbL. Preserve the license attached to the exact artifact used.

## Conservative publication checklist

- Keep a visible “© OpenStreetMap contributors” link to https://www.openstreetmap.org/copyright on the sampled map and in exported renders.
- Publish the supplied ODbL city-buildings.json, selected GeoJSON and notices beside the app. Preserve source IDs, dates and height assumptions. No project-specific evidence is bundled into these geographic datasets.
- For later CC BY assets, credit creator/source, link the license, and identify transformations. For CDLA datasets, include the agreement text with redistributed data.
- Do not scrape proprietary map imagery or assume a public viewer grants extraction rights. A data license is separate from an API hosting policy.
- Cached self-hosted assets avoid hitting public services during every camera movement. Check provider limits again before scheduled refreshes.
